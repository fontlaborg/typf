Struct GlyphCache

pub struct GlyphCache { /* private fields */ }
Expand description

Byte-weighted render output cache

Uses byte-weighted eviction (not entry count) to prevent memory explosions. Default limit is 512 MB, configurable via TYPF_CACHE_MAX_BYTES.
