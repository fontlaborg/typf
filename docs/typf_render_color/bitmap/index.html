Bitmap glyph rendering support

Renders embedded bitmap glyphs (sbix, CBDT/CBLC) using skrifa’s bitmap module. Supports PNG, BGRA, and mask formats.

When a bitmap glyph is unavailable, the render_bitmap_glyph_or_outline function falls back to rendering the glyph outline.

§Scaling

Bitmap fonts store glyphs at specific pixel sizes (strikes). When rendering at a different size, we scale the bitmap using bilinear interpolation and flip vertically to convert from bitmap coordinates (Y-down) to font coordinates (Y-up).
