Struct TypfFontFace 

Source 
pub struct TypfFontFace { /* private fields */ }
Expand description

In-memory font face ready for shaping and rendering.

The face keeps the original font bytes and recreates parser views on demand. For collection files such as TTCs, face_index selects the face inside the shared file.
