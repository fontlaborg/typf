Arguments for the render command

Fields§

§text: Option<String>

Input text to render (reads from stdin if omitted)

§font_file: Option<PathBuf>

Font file path (.ttf, .otf, .ttc, .otc)

§face_index: u32

Face index for TTC/OTC collections

§instance: Option<String>

Named/dynamic instance spec

§text_arg: Option<String>

Input text (alternative to positional argument)

§text_file: Option<PathBuf>

Read input text from file

§shaper: String

Shaping backend: auto, none, hb, icu-hb, mac, win (ignored when using linra renderer)

§renderer: String

Rendering backend: auto, opixa, skia, zeno, vello, vello-cpu, mac, win, json, linra-mac, linra-win vello uses GPU acceleration via wgpu; vello-cpu is CPU-only Linra backends (linra-mac, linra-win) perform shaping AND rendering in one pass

§direction: String

Text direction: auto, ltr, rtl, ttb, btt

§language: Option<String>

Language tag (BCP 47), e.g., en, ar, zh-Hans

§script: String

Script tag (ISO 15924), e.g., Latn, Arab, Hans

§features: Option<String>

Font feature settings (comma or space separated)

§font_size: String

Font size in pixels (or ‘em’ for UPM)

§line_height: u32

Line height as % of font size

§width_height: String

Canvas size spec: x, x, x, or none

§margin: u32

Margin in pixels

§hinting: String

Outline hinting: none, tt (TrueType instructions via typftth; opixa only)

§ppem: Option<u32>

Integer pixels-per-em to hint at (default: rounded font size)

§font_optical_sizing: String

Optical sizing: auto, none

§foreground: String

Text color (RRGGBB or RRGGBBAA)

§background: String

Background color (RRGGBB or RRGGBBAA)

§color_palette: u32

Font CPAL palette index

§glyph_source: Vec<String>

Glyph source preferences or deny list.

Control which glyph data sources are used and in what order. Sources: glyf, cff, cff2, colr0, colr1, svg, sbix, cbdt, ebdt

Examples: –glyph-source prefer=glyf,cff2 Use outline sources first –glyph-source deny=colr0,colr1,svg Disable all color sources –glyph-source prefer=colr1,colr0,svg Prefer COLR over SVG –glyph-source deny=sbix,cbdt,ebdt Disable bitmap sources

§no_shaping_cache: bool

Disable shaping cache (enabled by default)

§no_glyph_cache: bool

Disable glyph/render cache (enabled by default)

§output_file: Option<PathBuf>

Output file path (stdout if omitted)

§format: OutputFormat

Output format: pbm, png1, pgm, png4, png8, png, svg

§quiet: bool

Silent mode (no progress info)

§verbose: bool

Verbose output
